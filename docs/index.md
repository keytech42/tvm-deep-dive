# 🏛️ TVM System Engineering Journey

Welcome to the documentation for building and analyzing Apache TVM from source.

## Overview

This repository contains my personal journey of setting up, compiling, and exploring the TVM Deep Learning Compiler on macOS.

Here, you will find:
- **[Journal](journal/01_environment_and_clone.md):** Step-by-step logs of environment setup, CMake configurations, and compilation troubleshooting.
- **Notes:** Theoretical concepts like TensorIR, Operator Fusion, and the FFI boundary.

By building from source, we gain access to explicit hardware features and a deeper understanding of TVM's internal execution paths.
